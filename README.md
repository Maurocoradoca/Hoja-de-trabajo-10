# Hoja-de-trabajo-10


## Ingreso de Datos
Para que el programa encuentre las rutas y reconozca las ciudades correctamente, siga estas reglas estrictas al momento de ingresar texto en la consola:

* **Ingreso individual por solicitud:** * En **"Origen:"**, escriba **únicamente** el nombre de la ciudad de partida y presione Enter (Ejemplo: `Guatemala`).
En **"Destino:"**, escriba **únicamente** el nombre de la ciudad de llegada y presione Enter (Ejemplo: `Mixco`).
* **Distancias:** Ingrese únicamente valores numéricos al agregar nuevas rutas (Ejemplo: `25` o `30.5`).
